# 基礎知識

## hello world

基本的な zinc プログラムのソースコードは次のとおりである：

```rust
fn main() {
    println("hello world");
}
```

ソースコードファイルは `.zn` 拡張子で終わり、ファイル内容は utf8 で符号化しなければならない。コンパイルコマンドは：

```
zinc main.zn
```

実行が終わると、現在のフォルダに新しく生成された実行可能プログラムが見える。このプログラムを実行すると、`hello world` という文字列が印字される。

## コメント

zinc は二種類のコメントをサポートする：行コメントとブロックコメント。

1. 行コメント

    行コメントは `//` で始まり、その行の末尾まで続く。

2. ブロックコメント

    ブロックコメントは `/*` で始まり、最初の `*/` まで続く。

## 関数

普通の zinc 関数定義は、`fn` キーワードで始まり、その後に関数名と一対の丸括弧が続き、丸括弧の内部はこの関数の引数リストである。丸括弧の後ろに関数の戻り型を書ける。その後ろが波括弧で囲まれた関数本体である。

例は次のとおり：

```rust
fn my_func(arg1: Int32, arg2: String) -> Bool {
    return true;
}
```

zinc プロジェクトが実行可能プログラムを生成する必要があるなら、ルートモジュールに唯一の `main` 関数を定義し、プログラム入口としなければならない。

## 変数と型

識別子：`_` または文字で始まり、後ろに `_` または数字または文字を許す。

単独の `_` は特殊な識別子で、無視を表す。

### 局所変数

局所変数は型を明示しなくてもよく、型推論を許す。

変数名が mut で修飾されていない場合、デフォルトで不変である。

```rust
fn main() {
    let x = 5_i;
    x = 6; // 誤り。x は不変である
}
```

可読性のため、同じ block 中の局所変数は、**重名を許さない**。異なる block 中の局所変数はもちろん重名できる。

### 静的変数

静的変数の定義は `static` キーワードで修飾する。

静的変数の型は `Send` 制約を満たす必要がある（どの型が `Send` を満たすかは Rust と異なることに注意）。「並列と並行」の章を参照。un-Send 型を static 変数として使うなら、unsafe で修飾しなければならない。

静的変数は定義時に初期化しなければならず、初期化式は「定数式」だけである。

静的変数は mut 修飾を付けられる。しかし mut 静的変数は unsafe で修飾しなければならない。それへの読み書きは、すべて unsafe コンテキスト中で行わなければならない。

```rust
unsafe static mut G: Int32 = 1; // mut 修飾付きの static 変数、あるいは型が Send を満たさない static 変数は、unsafe で修飾しなければならない

fn main() {
    println(G.to_string()); // 誤り。G は unsafe コンテキスト中でのみ使える
}
```

> **計画中の機能**：今後、static 変数の型推論をサポートできる。

### 定数

定数の定義は `const` キーワードで修飾する。

静的変数と同様に、定数の型は `Send` 制約を満たさなければならない。定数は定義時に初期化しなければならず、初期化式は「定数式」だけである。

定数は mut 修飾を付けられない。

```
const PI: F32 = 3.14;
```
> **計画中の機能**：今後、const 定数の型推論をサポートできる。
