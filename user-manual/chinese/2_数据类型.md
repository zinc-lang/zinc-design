
# 基本数据类型

命名规范：所有具名类型，类型名字都是大驼峰命名法 UpperCamelCase。（ `fn` 关键字除外，因为这个关键字主要用在函数定义场景。 ）

## Bool 类型

`Bool` 类型共有两个可能的取值，`true` 和 `false`。

`Bool` 类型取反，用 `!` 运算符。

## 整数

|  长度 |  有符号  |  无符号  |
|-------|---------|----------|
| 8 bit | Int8      |  UInt8      |
| 16 bit | Int16      |  UInt16      |
| 32 bit | Int32      |  UInt32      |
| 64 bit | Int64      |  UInt64      |
| arch-dependent | Int      |  UInt  |
| arch-dependent | Short    | UShort  |

Int/UInt 类型的大小，与目标平台有关。在64位平台上，它们就是 64 bit 大小；在32位平台上，它们就是 32 bit 大小。等价于 C 语言的 `intptr_t` / `uintptr_t`。
Short/UShort 类型的大小，与目标平台有关，总是 Int/UInt 类型的一半。在64位平台上，它们就是 32 bit 大小；在32位平台上，它们就是 16 bit 大小。


整数字面量，允许 `_` 做分隔符。

允许前缀区分进制，`0o` 代表八进制，`0x` 代表十六进制， `0b` 代表二进制。

整数字面量，允许后缀类型。后缀类型为小写，比如 `123_i8`  `100_i`  `0x64_u`。
在没有其它上下文信息情况下，整数字面量无法推导出类型。建议用户给整数字面量加上类型后缀，显式表明它的类型。

整数算术运算，发生溢出时一律是 wrapping 模式。如果需要其它行为，请调用标准库。标准库为整数提供 `checked_add` / `wrapping_add` / `saturating_add` 以及对应的 `sub`/`mul` 成员函数。

zinc 不提供 "位运算" 运算符，包括 左移、右移、按位与、按位或、按位非、按位异或。
而是在标准库中给整数类型提供了成员函数完成位运算，比如 `bit_and`，足够满足功能要求。

原因：位运算操作使用频率很低，而且只适用于整数类型，专门设计运算符有点浪费。
况且位运算本来也不止上述这些功能，还有 rotate、reverse、count_ones 等等不常用的上十种位运算功能。这些本来也只能用成员函数的方式提供。个人感觉不如把所有位运算功能都用成员函数提供，更一致。
ASCII 码里面的符号本来就不怎么够用，这些符号留着给其它更重要的功能更合理。


## 浮点数

浮点数分为 `F32` 和 `F64` 类型。

浮点数字面量，允许 `_` 做分隔符。
浮点字面量，允许后缀类型，分别为 `f32` 和 `f64`。

浮点字面量，不允许省略小数点前面的 0。 `.123` 或者 `-.1` 均报错。

## 字符类型 Char

`Char` 类型是 32 bit，代表一个 unicode code point。

`Char` 字面量用单引号包围。比如 `'好'`。

`Char` 字面量允许转义。`'\u{3456}'`。

支持 Byte 字面量， `b'a'`。Byte 字面量的值只能是 ascii 字符，它的类型为 `UInt8`。

标准库中有一个类型别名定义 `type Byte = UInt8;`。

## 数组

数组内的元素都是同样的类型。数组的长度必须是编译时常量。

元素为 `T` 类型，长度为 `N` 的数组类型，表示为 `[T; N]`。数组是值类型，数组类型在赋值、传参、返回的时候，会拷贝所有元素。

示例如下：

```rust
fn main() {
    let x: [Int; 3] = [1, 2, 3];
}
```

数组字面量有两种表达形式：

1. 在中括号中直接列出来所有的元素，用逗号分隔。

    `[1, 2, 3]`

2. 在中括号中把元素和个数用分号分隔，代表多个重复元素。

    `[1; 3]`

访问数组元素，使用索引表达式，越界的时候出现 panic。示例如下：

```rust
fn main() {
    let mut x: [Int; 3] = [1, 2, 3];
    x[1] = 10;
    println(x[5]); // 编译通过，执行阶段发生 panic
}
```

## 切片

数组切片是指向数组一部分的借用指针。数组切片分两种 `Slice<'a, T>` 和 `SliceMut<'a, T>`， 分别代表只读权限，和可读写权限。

```rust
fn main() {
    let x: [Int; 3] = [1, 2, 3];
    let s: Slice<Int> = &x;
    println(s.len());
    println(s[1]);
}
```

数组切片是带有生命周期的结构体，可看做是带有额外元数据的借用指针。上例中的 `s` 变量是两个指针大小，分别保存有起始地址，以及长度。

注：之所以不使用 rust 中的 `&[T]` 语法，是希望简化类型系统和实现难度。
在 rust 中，`[T]` 是一个合法类型，可以独立使用，且是 dyn sized。这会给类型系统带来一种特例，在实现泛型的时候很麻烦。zinc 希望用户只能使用 `&[T]/&mut [T]` 类型，没有单独的 dyn sized 的 `[T]` 类型，也没有 `Box<[T]>` `Rc<[T]>` 等类型。
因此换掉了 `&[T]/&mut[T]` 语法，只在标准库提供 `Slice/SliceMut` 类型。它的语义相当于 rust 中强制要求 `[T]` 只能和借用指针合并到一起使用。Zinc 的 `Slice<'a, T>` 等价于 Rust 的 `&'a [T]`。

> Range 类型已实现：开区间 `..<` 对应 `RangeExclusive<T>`，闭区间 `..=` 对应 `RangeInclusive<T>`。整数类型实现了 `Step`，因此可以 `for i in 0_i ..< 10_i`。取消 `RangeFull`。
切片操作暂时还不能用索引运算符`[]` 配合 Range 类型实现，因为运算符重载还没实现。
```
let s: Slice<Int> = &x[1..<3]; // 后续支持
```

## 字符串

字符串分两种类型，`Str` 和 `String`。

`Str` 是定义在标准库中的带有生命周期的结构体 `struct Str<'a>`。 `String` 类型是定义在标准库中的，基于 `Vec<UInt8>` 类型实现的，不带生命周期的结构体。

字符串字面量是 `Str<'static>` 类型。

注：与数组切片类似，之所以不使用 rust 中的 `str` 关键字，是希望简化类型系统和实现难度。
在 rust 中，`str` 是一个合法类型，可以独立使用，且是 dyn sized。这会给类型系统带来一种特例，在实现泛型的时候很麻烦。zinc 希望用户只能使用 `&str` 类型，没有单独的 dyn sized 的 `str` 类型，也没有 `Box<str>` `Rc<str>` 等类型。
因此换掉了 `str` 关键字，只在标准库提供 `Str` 类型。它的语义相当于 rust 中强制要求 `str` 只能和只读借用指针合并到一起使用。Zinc 的 `Str<'a>` 等价于 Rust 的 `&'a str`。

字符串内部是 utf8 编码。

用 C++ 的思维来理解，zinc 的 `String` 就是对应 C++ 的 `std::string`，只不过内部实现用了 copy-on-write 机制。zinc 的 `Str` 就是对应 C++ 的 `std::string_view`，额外加上编译时生命周期检查。

字符串字面量支持转义。

支持 raw string literal：`r"content"`、`r#" content "#`、`r##" content "##`。也支持 C 字符串字面量 `c"..."`（类型仍是 `Str`，字节序列带结尾 NUL，便于传给 C）。

todo: 支持字符串插值 string interpolation，即在字符串字面量内部支持嵌套表达式。示例：

```
let name: Str = "Amy";
let s: String = f"hello $(name), how are you?";
```
选择使用小括号而不是大括号，是因为 zinc 里面小括号一般用于表达式场景。表达式有类型和值。大括号一般用于语句场景，语句没有类型没有值。

TODO: 目前内嵌表达式只支持最简单的单个变量名，后续增加支持所有的表达式。

## 元组 tuple

包含 0 个元素的元组，叫做单元类型 unit type。单元类型用 `()` 表示。空元组 `()` 表达式的类型就是单元类型。
如果省略函数返回类型，那么代表这个函数返回的是 `()` 类型。

包含 1 个元素的元组，需要一个额外的逗号做结尾，否则会被编译器判定为 “小括号表达式”，而不是元组。 `(1,)` 是元组，`(1)` 不是。

包含 2 个或者以上元素的元组，元素可以是不同的类型。

## 结构体 struct

使用 `struct` 关键字定义结构体。示例如下：

```rust
struct User {
    active: Bool,
    username: String,
    email: String,
}
```

结构体支持泛型。
结构体本身和结构体成员都允许用 pub 修饰。
结构体允许大括号内没有成员。

结构体的成员支持默认值，默认值必须是常量表达式。
```rust
struct User {
    active: Bool = true, // 默认值
    username: String = f"",
    email: String = f"",
}
```

结构体初始化表达式，与 C 语言类似：

```rust
let user: User = {  // 通过标注变量绑定的类型，指定结构体初始化表达式的类型
    .active = false,
    .username = "John".to_string(),
    .email = "john@gmail.com".to_string(),
};
// 或者
let user = {  // 通过类型后缀，指定结构体初始化表达式的类型
    .active = false,
    .username = "John".to_string(),
    .email = "john@gmail.com".to_string(),
} : User;
```

结构体不支持类似 C 语言的成员按顺序匿名初始化:
```
let user: User = { false, "John".to_string(), "john@gmail.com".to_string() };  // 错误
```

带有默认值的成员，可以不显式初始化。

支持用其它结构体初始化另外一个结构体。注意这里使用的是三个点 `...`，而不是 rust 的两个点 `..`。
在 zinc 中，统一用三个点 `...` 代表省略号。省略号语法在好几个场景都有用到。省略号后面可以带表达式也可以不带表达式。

```rust
// active 可以不用写，代表它用的默认值
let user1: User = { .username = "smith".to_string(), .email = String::new() };

// 使用 user1 初始化 user2，只是 active 这个成员的值有变化
let user2: User = { .active = true, ...user1 }; 

// 使用 User 类型定义中的默认值初始化 user3，只是 active 这个成员的值有变化
let user3: User = { .active = true, ... }; 

// 这种相当于全部使用 User 类型定义时的默认值初始化。
// 需要用省略号，否则词法分析无法区分空的结构体初始化和空的语句块
let user4: User = { ... }; 
```

结构体不支持继承。zinc 准备通过 trait 继承，以及 `reuse` 机制支持面向对象编程范式。

zinc 不准备支持 tuple struct，即成员变量没有名字的结构体。建议对于简单结构体，单独提供一个对应的 snake_case 命名的全局函数作为 “构造函数” 使用。
这样语言规则比较简练统一，从使用的角度来看，命名规范也比较统一。不会有大写字母开头的 “类似函数” 的东西出现。
比如：

```rust
struct Weight {
    w: UInt32
}

fn weight(w: UInt32) -> Weight {
    return { .w = w };
}

fn main() {
    // 定义方稍微麻烦一点，使用方基本上跟 tuple struct 没区别
    let w = weight(1); 
}
```

zinc 支持 “单元结构体”。没有成员变量的结构体，可以用分号结尾，也可以大括号内部为空：
```rust
// 以下两种写法是一样的
struct Unit{} 
struct Unit;
```
但是注意，单元结构体的初始化，依然还是需要大括号才行：
```
let x: Unit = { ... };
```

## 枚举体 enum

枚举体用 `enum` 关键字定义：

```rust
enum IpAddrKind {
    V4,
    V6,
}

fn main() {
    let k: IpAddrKind = IpAddrKind::V4;
}
```

枚举体的成员支持关联值。
```rust
enum IpAddr {
    V4(Byte, Byte, Byte, Byte),
    V6(String),
}
```

不支持大括号关联值。如果用户需要参数命名，建议把所有参数用结构体包装一下，效果是一样的：

```rust
enum E {
    A{ x:Byte, y: String } // 错误
}
// 替代写法:
struct EA {
    x: Byte,
    y: String,
}
enum E {
    A(EA),
}
```

支持枚举体成员重载，规则与函数重载一样，只支持不同参数数量的重载。

```rust
enum Arg {
    Integer(UInt),
    Integer(UInt, UInt),
    Integer(UInt, UInt, UInt),
    Float(F64),
    Float(F64, F64),
    Float(F64, F64, F64),
}
```

枚举本质上是带标签的联合体(tagged union)。允许用户自定义的 enum 指定 tag 是哪种整数类型，以及每个成员对应的标签的值。
标签值必须是常量表达式，值必须能在对应的整数中表达，且每个成员对应的标签值不能重复。

只允许不带关联值的 enum 指定 tag 的值。

```rust
enum IpAddr : UInt8 {
    V4 = 1,  //
    V6 = 2,
}
```

允许不带关联值的 enum 通过 `as` 运算符直接与整数做类型转换。

枚举类型定义支持泛型。枚举的成员不允许引入新的泛型。

> **计划中的功能**：支持定义非详尽枚举(non-exhaustive enum)，语法为在最后一个成员后面使用省略号：
```rust
enum Puctuation {
    Comma,
    Dot,
    Semi,
    ...  // 省略号，相当于 Rust 中用 #[non_exhaustive] 修饰 enum
}
```

## 联合体 union

联合体用关键字 `union` 定义。联合体的整体大小，取决于最大的成员的大小。

```
union U {
    data1: Byte,
    data2: UInt,
}
```

union 类型是不安全的，读写 union 类型的成员，都需要在 unsafe 上下文中进行。

对 union 的初始化语法与 struct 初始化语法类似。但要求只能选择其中一个成员做初始化。

non-trivial 类型，不能用做 union 类型的成员变量。
non-trivial 类型包括：
1. 带有析构函数的类型，比如 Arc/Weak 等
2. 带有生命周期参数的类型，比如 &/&mut 等
3. 如果 struct 的成员变量有 non-trivial 类型，则这个 struct 是 non-trivial
4. 如果 enum 的关联值有 non-trivial 类型，则这个 enum 是 non-trivial
5. 如果数组类型的元素是 non-trivial 类型，则这个数组是 non-trivial
6. 如果 tuple 类型的元素包含 non-trivial 类型，则这个 tuple 是 non-trivial

union 类型定义不允许带有泛型参数。

union 主要有两种使用场景：
1. 用于与 C 交互的场景
2. 用于按位类型转换的场景 (类似 rust 的 `std::mem::transmute`)

比如，如果我想实现从 `F32` 类型按位转为 `UInt32` 类型，就可以用 union 帮忙完成：
```rust
union FloatOrInt {
    f: F32,
    i: UInt32,
}

fn bit_cast_f32_to_uint32(f: F32) -> UInt32 {
    let u: FloatOrInt = { .f = f };
    return unsafe(u.i);
}
```

## 类型的大小

类型分为 Sized 和 UnSized。 Sized 类型可以用做局部变量、全局变量、成员变量，而 UnSized 类型不行，它们只能通过指针间接访问。

UnSized 类型包括：
1. `extern type` 声明的类型
    * `extern type` 主要用于互操作场景。它的含义是声明一个类型的定义是在其它语言中，在 zinc 中拿不到这个类型的定义。也就不知道它的大小，无法直接访问它的成员变量。

2. 所有的 trait
    * 假设定义了 `trait R`，不可以声明变量的类型是 `R`，但可以是 `&R / &mut R / *R` 等

3. 显式 `impl UnSized for S {}` 的自定义类型 `S`
    * `UnSized` 是一个内置 trait，允许用户指定自定义类型也是 Unsized，方式为 `impl UnSized for MyType {}`。
        这么做的目的是，禁止这个类型作为 “值语义类型” 使用，只允许用指针指向它使用，这个类型只需要 “引用语义类型”。
        一个典型场景就是标准库中的 `File` 类型。这个类型就不允许用户通过 “值语义类型” 的方式使用，用户只能拿到指向 `File` 的指针类型。

在泛型场景，目前不允许 UnSized 类型作为泛型实参。
