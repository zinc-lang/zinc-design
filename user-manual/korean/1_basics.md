# 기초 지식

## hello world

기본적인 zinc 프로그램 소스 코드는 다음과 같습니다:

```rust
fn main() {
    println("hello world");
}
```

소스 코드 파일은 `.zn` 확장자로 끝나며, 파일 내용은 반드시 utf8로 인코딩되어야 합니다. 컴파일 명령은 다음과 같습니다:

```
zinc main.zn
```

실행이 끝나면 현재 폴더에 새로 생성된 실행 프로그램을 볼 수 있습니다. 이 프로그램을 실행하면 `hello world` 문자열을 출력할 수 있습니다.

## 주석

zinc는 두 가지 주석을 지원합니다: 줄 주석과 블록 주석.

1. 줄 주석

    줄 주석은 `//`로 시작해 해당 줄 끝까지입니다.

2. 블록 주석

    블록 주석은 `/*`로 시작해 첫 번째 `*/`까지입니다.

## 함수

일반적인 zinc 함수 정의는 `fn` 키워드로 시작하고, 그다음에 함수 이름과 한 쌍의 원괄호가 오며, 원괄호 안은 이 함수의 매개변수 목록입니다. 원괄호 뒤에는 함수의 반환 타입을 쓸 수 있습니다. 그다음은 중괄호로 둘러싼 함수 본체입니다.

예시는 다음과 같습니다:

```rust
fn my_func(arg1: Int32, arg2: String) -> Bool {
    return true;
}
```

어떤 zinc 프로젝트가 실행 프로그램을 생성해야 한다면, 루트 모듈에 유일한 `main` 함수를 정의해 프로그램 진입점으로 삼아야 합니다.

## 변수와 타입

식별자: `_` 또는 문자로 시작하고, 뒤에는 `_` 또는 숫자 또는 문자가 허용됩니다.

단독 `_`는 특수한 식별자로, 무시를 나타냅니다.

### 지역 변수

지역 변수는 타입을 명시적으로 표시하지 않아도 되며, 타입 추론이 허용됩니다.

변수 이름에 mut이 붙지 않은 경우, 기본값은 불변입니다.

```rust
fn main() {
    let x = 5_i;
    x = 6; // 오류, x는 불변
}
```

가독성을 위해, 같은 block 안의 지역 변수는 이름 중복이 **허용되지 않습니다**. 서로 다른 block의 지역 변수는 물론 이름이 같아도 됩니다.

### 정적 변수

정적 변수 정의는 `static` 키워드로 수식합니다.

정적 변수의 타입은 `Send` 제약을 만족해야 합니다(어떤 타입이 `Send`를 만족하는지는 Rust와 다릅니다). “병렬과 동시성” 장을 참고하십시오. un-Send 타입을 static 변수로 쓰려면 반드시 unsafe로 수식해야 합니다.

정적 변수는 정의 시 반드시 초기화해야 하며, 초기화 표현식은 “상수 표현식”만 가능합니다.

정적 변수는 mut 수식을 붙일 수 있습니다. 하지만 mut 정적 변수는 반드시 unsafe로 수식해야 합니다. 그에 대한 읽기·쓰기는 모두 unsafe 컨텍스트에서 해야 합니다.

```rust
unsafe static mut G: Int32 = 1; // mut이 붙은 static 변수, 또는 타입이 Send를 만족하지 않는 static 변수는 반드시 unsafe로 수식해야 함

fn main() {
    println(G.to_string()); // 오류, G는 unsafe 컨텍스트에서만 사용할 수 있음
}
```

> **계획 중인 기능**: 이후 static 변수의 타입 추론을 지원할 수 있습니다.

### 상수

상수 정의는 `const` 키워드로 수식합니다.

정적 변수와 마찬가지로, 상수의 타입은 반드시 `Send` 제약을 만족해야 합니다. 상수 정의 시 반드시 초기화해야 하며, 초기화 표현식은 “상수 표현식”만 가능합니다.

상수에는 mut 수식을 붙일 수 없습니다.

```
const PI: F32 = 3.14;
```
> **계획 중인 기능**: 이후 const 상수의 타입 추론을 지원할 수 있습니다.
